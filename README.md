# BLIXX — Painel de teste da operação Total

Publicação de teste do dashboard. O painel processa as planilhas anexadas no navegador de cada usuário.

Nenhuma planilha de cliente está incluída neste repositório.

Para atualizar a publicação, substituir index.html pela versão completa aprovada do painel. GitHub Pages deve publicar a branch main, pasta raiz.
